# Альтернативное распределение фич

## Идея

Перераспределить фичи так, чтобы у каждого участника было примерно поровну баллов.

---

## Сравнение распределений

### Текущий план

| Участник   | Фичи                            | Баллы |
| ---------- | ------------------------------- | ----- |
| Участник 1 | 2, 5, 6, инфра, favicon, footer | 145   |
| Участник 2 | 1, 3                            | 180   |
| Участник 3 | 4, 7                            | 175   |

### Новое предложение

| Участник   | Фичи                            | Баллы       |
| ---------- | ------------------------------- | ----------- |
| Участник 1 | 1, 2, 5, инфра, favicon, footer | 180         |
| Участник 2 | 3, 7                            | 175         |
| Участник 3 | 4, 8                            | 170         |
| Все трое   | 6 (About) — каждый про себя     | +~8 каждому |

### Что изменилось

- Feature 1 (Header, 60 баллов) — переходит от Участника 2 к Участнику 1
- Feature 7 (i18n + sticky header + errors, 55 баллов) — переходит от Участника 3 к Участнику 2
- Feature 8 (YouTube видео, 50 баллов) — переходит от «все вместе» к Участнику 3
- Feature 6 (About, 25 баллов) — делится на троих вместо одного участника

---

## Зависимости при новом распределении

Feature 1 (Header) зависит от Feature 2 (auth) — обе теперь у Участника 1, это даже лучше чем было.

Feature 7 (i18n) требует готового хедера — хедер у Участника 1, i18n у Участника 2. Участник 2 просто добавит переключатель языка в хедер когда дойдёт до Feature 7, это стандартная точка интеграции и не блокирует основную работу.

```
[Участник 1]
│
├── Инфраструктура + БД/Auth
│         │
│         ▼
├── Feature 2: Sign In / Sign Up
│         │
│         ├──────────────────────────────► [Участник 2]
│         │                                │
│         ▼                                ├── Feature 3: Swagger Editor ← старт сразу
├── Feature 1: Header (ждёт Feature 2)     │         │
│         │                                │         ▼
│         └──────────────────────────────► │    [Участник 3]
│              (добавить i18n-toggle)       │    │
│                                          │    ├── Feature 4: Swagger Viewer + Try-It-Out
│                                          │    │
│                                          │    └── Feature 8: YouTube видео
│                                          │
│                                          └── Feature 7: i18n, sticky header, errors
│                                               (добавляет toggle в хедер Участника 1)
│
├── Feature 5: History & Analytics ◄── ждёт Feature 2 (своя) + Feature 4 (Участник 3)
│
└── Feature 6: About Page ◄── каждый добавляет свой кусок
```
